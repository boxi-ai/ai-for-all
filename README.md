# AI 通识课 · AI Literacy for Everyone

人人会用、人人会验、人人知道何时不用。一套给所有人的 AI 通识课：8 个共享核心模块（C1–C8），按人群分成儿童 / K12、
大学专业、在职、银发族、教师几条路线；每个模块有讲义、短视频和互动网页。

在线阅读：https://boxi-ai.github.io/ai-for-all/

本仓库只放网站的静态文件（HTML / CSS / JS），由 GitHub Pages 从 `main` 根目录提供。
